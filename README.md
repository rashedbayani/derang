# درنگ

بازخورد خصوصی در جمع دوستان. رابط فارسی و راست‌به‌چپ با وزیرمتن، ورودی کد دعوت برای اعضا و ورودی ایمیل و رمز عبور برای مدیر.

## اجرای محلی

نیازمند Node.js 24+. وابستگی‌ها را با `npm install` نصب کنید. در یک ترمینال، متغیرهای `ADMIN_EMAIL`، `ADMIN_PASSWORD` (حداقل ۱۲ کاراکتر) و `DERANG_SECRET` (حداقل ۳۲ کاراکتر تصادفی) را تنظیم کنید و `npm run api` را اجرا کنید. نمونهٔ تولید راز با `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` است. در ترمینال دیگر `npm start` را اجرا کنید و به http://localhost:4200 بروید. تست API با `npm test` اجرا می‌شود.

## انتشار

نسخهٔ آنلاین فرانت‌اند روی GitHub Pages و بک‌اند روی Supabase است. گردش کار GitHub Actions به‌صورت پیش‌فرض از آدرس API همین پروژه استفاده می‌کند و سلامت API و هدر CORS را پیش از انتشار بررسی می‌کند. برای انتشار روی پروژه‌ای دیگر، متغیر عمومی `DERANG_API_BASE` را با آدرس تابع Edge تنظیم کنید.

- ساختار پایگاه داده در `supabase/migrations` و تابع Edge در `supabase/functions/derang` است. هنگام تغییر پرسش‌ها، نسخهٔ همراه تابع را با `shared/questions.json` هماهنگ کنید.
- هنگام انتقال به پروژهٔ دیگر، مقدار `origin` در تابع را با آدرس فرانت‌اند هماهنگ کنید. احراز هویت در خود تابع انجام می‌شود. کلید سرویس Supabase فقط در محیط اجرای تابع استفاده می‌شود.
- برای مدیر، کاربر ایمیل و رمز را در **Authentication → Users** بسازید و شناسهٔ همان کاربر را به `derang.admins` اضافه کنید. تنها کاربران ثبت‌شده در این جدول امکان ورود مدیریتی دارند.

## رفتار

هر گروه یک دوره دارد. مدیر می‌تواند حداکثر سه دستهٔ تکمیلی انتخاب کند، عضو اضافه کند و کد تازه را یک‌بار ببیند. ارسال کد به‌صورت خصوصی با مدیر است. عضو پس از ورود با کد مستقیماً گروه خود را می‌بیند. فرم دارای ۱۲ سؤال اصلی و بانک تکمیلی ۳۰ سؤالی است. ظاهر، گفت‌وگوی سیاسی و متن اختیاری‌اند و رضایت گیرنده می‌خواهند. هر عضو یک بار برای هر دوست پاسخ می‌دهد. سرور از ثبت هم‌زمان پاسخ تکراری جلوگیری می‌کند.

پس از پایان دوره، هر عضو گزارش خودش را می‌بیند. هر سؤال به حداقل سه پاسخ معتبر نیاز دارد. پاسخ‌های عددی مستقیماً در جمع و تعداد هر سؤال ادغام می‌شوند. رسید ثبت بازخورد برای جلوگیری از تکرار جداست. نظرات متنی بدون شناسهٔ نویسنده نگهداری و پس از رسیدن به حداقل سه نظر هم‌نوع نمایش داده می‌شوند. متن آزاد ممکن است از روی لحن یا جزئیات قابل‌شناسایی باشد. مدیر در رابط برنامه به پاسخ‌ها و گزارش اعضا دسترسی ندارد. دسترسی به پایگاه دادهٔ عملیاتی و پشتیبان آن فقط در اختیار اپراتور سرویس باشد.
