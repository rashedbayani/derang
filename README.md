# درنگ

بازخورد خصوصی در جمع دوستان، با رابط فارسی و راست‌به‌چپ و فونت وزیرمتن.

- هر نفر می‌تواند گروه بسازد. کلید گروه برای اعضا و کلید مدیریت برای سازنده است. کلید مدیریت هنگام ساخت فقط یک‌بار نمایش داده می‌شود.
- سازنده یک لینک دعوت مشترک برای گروه دارد و می‌تواند آن را برای چند نفر بفرستد. افراد با لینک یا کلید گروه درخواست عضویت می‌دهند و کلید شخصی خودشان را می‌گیرند. سازنده هر درخواست را تأیید یا رد می‌کند.
- اعضا با کلید گروه و کلید شخصی وارد می‌شوند. هر عضو یک بار برای هر دوست بازخورد می‌دهد. پس از مهلت یا پایان دستی دوره، نتایج خصوصی با حداقل سه پاسخ معتبر نمایش داده می‌شوند.

## اجرا و انتشار

رابط Angular با Node.js 24، دستور `npm install` و سپس `npm start` اجرا می‌شود. پراکسی توسعه درخواست‌ها را به API آنلاین درنگ می‌فرستد، بنابراین عملیات واقعی به همان پایگاه داده می‌روند. پرسش‌نامهٔ تابع Edge در پوشهٔ همان تابع قرار دارد و باید با `shared/questions.json` هماهنگ باشد. تست `npm test` مربوط به پیاده‌سازی اولیهٔ محلی است.

GitHub Actions رابط را روی Pages منتشر می‌کند. مقدار `DERANG_API_BASE` می‌تواند آدرس تابع Edge را برای استقرار دیگری مشخص کند. برای استقرار بک‌اند، مهاجرت‌های `supabase/migrations` را اعمال و تابع `derang-v2` را منتشر کنید. احراز هویت در خود تابع انجام می‌شود و کلید سرویس Supabase فقط در محیط سرور استفاده می‌شود. آدرس فرانت‌اند مجاز در تابع تنظیم شده است.

## جمع‌بندی هوش مصنوعی

در تنظیمات Secrets توابع Edge پروژه، `OPENAI_API_KEY` را تعریف کنید. پس از پایان دوره، هر عضو با دست‌کم دو نتیجهٔ قابل‌نمایش می‌تواند جمع‌بندی فارسی خودش را درخواست کند. درخواست سرور فقط شامل متن عمومی پرسش‌ها، نوع مقیاس، میانگین و تعداد پاسخ‌های معتبر است. پاسخ در پایگاه داده برای همان عضو نگهداری می‌شود. بدون کلید API، گزارش عددی همچنان در دسترس است.
