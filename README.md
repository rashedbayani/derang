# درنگ

بازخورد خصوصی در جمع دوستان. رابط فارسی و راست‌به‌چپ با وزیرمتن، ورودی کد دعوت برای اعضا و ورودی ایمیل و رمز عبور برای مدیر.

## اجرای محلی

نیازمند Node.js 24+. وابستگی‌ها را با `npm install` نصب کنید. در یک ترمینال، متغیرهای `ADMIN_EMAIL`، `ADMIN_PASSWORD` (حداقل ۱۲ کاراکتر) و `DERANG_SECRET` (حداقل ۳۲ کاراکتر تصادفی) را تنظیم کنید و `npm run api` را اجرا کنید. نمونهٔ تولید راز با `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` است. در ترمینال دیگر `npm start` را اجرا کنید و به http://localhost:4200 بروید. تست API با `npm test` اجرا می‌شود.

## انتشار

۱. سرویس Node.js را با دستور `npm run api` روی یک میزبان HTTPS اجرا کنید. `DERANG_DB` باید روی دیسک پایدار باشد. یک نمونهٔ سرویس اجرا کنید. سه متغیر اجرای محلی را روی سرور ثبت کنید و `APP_ORIGIN` را برابر `https://rashedbayani.github.io` قرار دهید. `PORT` به‌طور پیش‌فرض ۸۷۸۷ است.

۲. در GitHub، بخش Settings → Pages → Source را روی GitHub Actions بگذارید. سپس در Settings → Secrets and variables → Actions → Variables، متغیر `DERANG_API_BASE` را روی نشانی HTTPS سرور با پایان `/api` قرار دهید. این متغیر عمومی است؛ اطلاعات ورود مدیر و راز سرور در محیط بک‌اند می‌مانند.

۳. گردش کار Build and publish Derang را روی main اجرا کنید. نشانی مورد انتظار `https://rashedbayani.github.io/derang/` است. اگر نشانی API تنظیم نشود، صفحهٔ عمومی باز می‌شود و دکمه‌های ورود غیرفعال‌اند.

## رفتار

هر گروه یک دوره دارد. مدیر می‌تواند حداکثر سه دستهٔ تکمیلی انتخاب کند، عضو اضافه کند و کد تازه را یک‌بار ببیند. ارسال کد به‌صورت خصوصی با مدیر است. عضو پس از ورود با کد مستقیماً گروه خود را می‌بیند. فرم دارای ۱۲ سؤال اصلی و بانک تکمیلی ۳۰ سؤالی است. ظاهر، گفت‌وگوی سیاسی و متن اختیاری‌اند و رضایت گیرنده می‌خواهند. هر عضو یک بار برای هر دوست پاسخ می‌دهد. سرور از ثبت هم‌زمان پاسخ تکراری جلوگیری می‌کند.

پس از پایان دوره، هر عضو گزارش خودش را می‌بیند. هر سؤال به حداقل سه پاسخ معتبر نیاز دارد. پاسخ‌های عددی مستقیماً در جمع و تعداد هر سؤال ادغام می‌شوند. رسید ثبت بازخورد برای جلوگیری از تکرار جداست. نظرات متنی بدون شناسهٔ نویسنده نگهداری و پس از رسیدن به حداقل سه نظر هم‌نوع نمایش داده می‌شوند. متن آزاد ممکن است از روی لحن یا جزئیات قابل‌شناسایی باشد. مدیر در رابط برنامه به پاسخ‌ها و گزارش اعضا دسترسی ندارد. ذخیرهٔ پایدار SQLite و پشتیبان آن فقط در اختیار اپراتور سرویس باشد.

### میزبانی رایگان بک‌اند با alwaysdata

پلن Free برای استفادهٔ شخصی فضای پایدار دارد. در حساب کاربری، Node.js 24 را انتخاب کنید. در SSH یا Web Terminal حساب، مخزن را در پوشه‌ای خارج از مسیر عمومی وب دریافت کنید و پوشهٔ داده را بسازید:

```sh
git clone https://github.com/rashedbayani/derang.git ~/derang
mkdir -m 700 ~/derang-data
```

در بخش **Web → Sites** یک سایت از نوع **Node.js** بسازید و آدرس HTTPS رایگان حسابتان را به آن بدهید. فرمان اجرا `node /home/ACCOUNT/derang/server/index.mjs` است. به‌جای `ACCOUNT` نام حساب را بگذارید. نصب بسته برای بک‌اند لازم نیست. میزبان مقدار IP و PORT را فراهم می‌کند.

در تنظیمات محیط اجرای سایت، `ADMIN_EMAIL`، `ADMIN_PASSWORD`، و `DERANG_SECRET` را مطابق بخش اجرای محلی تنظیم کنید. مقدار `DERANG_DB` را `/home/ACCOUNT/derang-data/derang.sqlite` و مقدار `APP_ORIGIN` را `https://rashedbayani.github.io` بگذارید. از رمز تازه و طولانی استفاده کنید. فایل دیتابیس و رمزها در مخزن قرار نمی‌گیرند.

پس از شروع سایت، نشانی `https://ACCOUNT.alwaysdata.net/api/health` باید `{"ok":true}` برگرداند. آدرس `https://ACCOUNT.alwaysdata.net/api` را به عنوان متغیر `DERANG_API_BASE` در GitHub ثبت کنید و گردش کار انتشار را دوباره اجرا کنید. گردش کار پیش از انتشار، سلامت API و اجازهٔ درخواست از GitHub Pages را بررسی می‌کند.
